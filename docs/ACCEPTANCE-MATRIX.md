|---|---|---|
| A01 | داده پس از بستن و اجرای مجدد حفظ شود | بخشی؛ localStorage هست، آزمون اندروید ندارد |
| A02 | مشتری با فیلدهای کامل، جست‌وجو و جلوگیری از تکرار | ناقص |
| A03 | محصول، قیمت، واحد و موجودی همراه تاریخچه | ناقص |
| A04 | فاکتور چندمحصولی و محاسبات دقیق | ناقص |
| A05 | پرداخت جزئی، مانده و گردش حساب یکپارچه | ناقص |
| A06 | به‌روزرسانی اتمیک موجودی هنگام فروش | ناقص |
| A07 | اصلاح/لغو با حفظ سابقه و جلوگیری از ثبت تکراری | ناقص |
| A08 | سررسید و مطالبات معوق | ناقص |
| A09 | گزارش‌های واقعی مبتنی بر داده | ناقص |
