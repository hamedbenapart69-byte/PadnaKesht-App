# پادناکِشت — مدیریت آفلاین کسب‌وکار

نسخهٔ در حال توسعهٔ برنامهٔ اندرویدی فارسی برای ثبت مشتری، محصول، موجودی، فاکتور فروش، دریافت‌های جزئی، ماندهٔ مشتری، گزارش‌ها و پشتیبان‌گیری.

## اجرای توسعه
```bash
npm install
npm test
npm run build
``

## قابلیت‌های پیاده‌سازی‌شده
- فرم‌های مشتری و محصول با ویرایش و جلوگیری از داده‌های تکراری
- فاکتور چندقلمی با محاسبات صحیح ریالی و کاهش موجودی
- ثبت دریافت جزئی، مانده، سررسید و ثبت رویدادهای حسابرسی
- گزارش فروش، گردش حساب مشتریان، مطالبات معوق و موجودی
- پشتیبان JSON، بازیابی ادغامی، حفظ رکوردهای نسخهٔ قبلی و CSV
- SQLite بومی برای Android همراه با نسخهٔ جایگزین localStorage در مرورگر

## ساخت اندروید
- گردش‌کار `.github/workflows/android-qa-build.yml` فقط APK آزمایشی برای بررسی داخلی تولید می‌کند.
- گردش‌کار `.github/workflows/android-apk.yml` قبل از ساخت نهایی، دروازهٔ پذیرش را اجرا می‌کند. تا زمان تکمیل شواهد پذیرش، ساخت APK نهایی عمداً مسدود است.

## مواردی که هنوز نهایی نشده‌اند
اجرای SQLite روی APK و آزمون نصب/حالت پرواز روی دستگاه واقعی، احراز هویت و حفاظت رمزنگاری‌شدهٔ داده، خروجی Excel واقعی، آزمون مستقل تقویم شمسی، و آزمون‌های کامل پذیرش مالی/انبار هنوز نیازمند بررسی و شواهد هستند. این نسخه را تا تکمیل موارد فوق نرم‌افزار حسابداری نهایی تلقی نکنید.
